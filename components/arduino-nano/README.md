# Arduino Nano

A 30-pin Arduino Nano or compatible module, soldered or socketed on two
15-pin headers. The origin is its upper-left header pin when the USB
connector faces north; keep that side clear for the cable.

Pins are numbered around the perimeter: pins 1–15 run down the left header and
pins 16–30 run back up the right header.

Clones differ in markings and outline. Check the pinout and dimensions of your
module before assembly, and copy the part to your project or user library to
adjust it.
