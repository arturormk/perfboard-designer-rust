# DIP-28, wide

A 28-pin dual in-line package, or its socket, with rows 15.24 mm apart. The holes between the rows are occupied.

Seen from above with the notch on the left, pin 1 is bottom left at `(0, 6)` and pins count anticlockwise, so pin 28 is top left at `(0, 0)`. Pins are named by number; copy the part to the project to name them after a particular chip.
