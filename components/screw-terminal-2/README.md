# Screw terminal, 2 positions

A PCB screw terminal block with 2 positions on the 5.08 mm pitch, so its pins use every other hole. It covers every hole around its pins: the holes between them, the hole beyond each end pin, and the rows in front of and behind them.

Wires enter from the south side (positive y). That side needs room for the wires and a screwdriver; it may overhang the board edge.
