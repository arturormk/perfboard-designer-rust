# Resistor 1/4 Watt

A generic 1/4 Watt axial resistor laid out across five perfboard holes in one
row. The body occupies the middle three holes, with one terminal hole at each
end.

The origin is terminal 1 at `(0, 0)`; terminal 2 is at `(4, 0)`. The component
may be placed horizontally or vertically using any 90-degree rotation.

This definition intentionally does not specify a resistance value. Record that
detail on the component instance or create a named variant when it matters to
the design.
