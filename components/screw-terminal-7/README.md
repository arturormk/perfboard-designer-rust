# Screw terminal, 7 positions

A PCB screw terminal block with 7 positions on the 5.08 mm pitch, so its pins use every other hole. It covers every hole around its pins: the holes between them, the hole beyond each end pin, and the rows in front of and behind them.

Screw terminal blocks are made to interlock: butted end to end, any number of them keep the 5.08 mm pitch, so their pins take alternating holes and the run covers only one hole at each end, like a single block. Use this part for two 2-position blocks and a 3-position one side by side. Placed as separate parts they could not sit that close: each claims the hole beyond its own end pins, so neighbouring blocks would overlap on the hole between them. A part's footprint does not change with its neighbours.

Wires enter from the south side (positive y). That side needs room for the wires and a screwdriver; it may overhang the board edge.
