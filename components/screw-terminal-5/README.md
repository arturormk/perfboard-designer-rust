# Screw terminal, 5 positions

A PCB screw terminal block with 5 positions on the 5.08 mm pitch, so its pins use every other hole. It covers the holes between its pins and the rows in front of and behind them; the holes beyond the end pins stay free.

Wires enter from the south side (positive y). That side needs room for the wires and a screwdriver; it may overhang the board edge.
