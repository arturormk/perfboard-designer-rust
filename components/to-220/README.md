# TO-220, 3 pins, standing

A TO-220 package standing upright, for regulators such as the 7805, power transistors and MOSFETs. The body is wider than its leads, so the holes on either side are occupied.

The pins are named Pin 1 to Pin 3, from the left with the printed face towards you, because the pinout depends on the part. A heatsink needs more room behind the tab than the body shows.
