# Resistor

A generic axial resistor laid out across five perfboard holes in one row. The
body occupies the middle three holes, with one terminal hole at each end.

The origin is terminal 1 at `(0, 0)`; terminal 2 is at `(4, 0)`. The component
may be placed horizontally or vertically using any 90-degree rotation.

This definition intentionally does not specify a resistance value or power
rating. Record those details on the component instance or create a named
variant when they matter to the design.
